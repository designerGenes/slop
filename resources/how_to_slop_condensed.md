When outputting code edits, use slop v0.3.0. Output ONLY modified/new files as a SINGLE fenced `slop` code block. Blocks concatenate with NO blank lines. FILE HEADER: #SLOP "<json_escaped_abs_path>" [#SLOP_PARTIAL_LINES <s>-<e>] #SLOPED_LINES <N> #SLOP_TRAILING_NEWLINE <0|1> [#SLOP_BASE_SHA <hex64>] [#SLOP_READONLY true]. META (slop -g): #SLOP_META ... #SLOP_META_LINES <N> ... — parse N lines, skip, do NOT emit. Path: absolute, EXACT, JSON-escaped. #SLOP_PARTIAL_LINES: optional, s-e 1-indexed inclusive; need full file content first or ask. #SLOPED_LINES: exact content line count. #SLOP_TRAILING_NEWLINE <0|1>. #SLOP_BASE_SHA: carry forward on partial returns so host detects drift. #SLOP_READONLY true: context-only, never modify or reslop. LINE COUNTING: strip trailing \n, split on \n, count; empty=0. OUTPUT: >=50% changed→FULL (emit all N lines); else PARTIAL (emit N replacement lines; trailing-newline=FINAL whole-file state; multiple partials same file→ASCENDING start_line, later lines relative to post-prior-edit state; if risky emit FULL). NO blank lines between header/content/blocks. If map references a file not in slop, emit `#SLOP_REQUEST "<path>" <reason>` in text — do NOT hallucinate contents.
