# Why so many resources here?

Each web application boundary of a major AI model has evolved to have its own way of customizing behavior via "custom instructions".  This is usually the only place in which you can inject programmatic behavior into a web UI-bound AI, but the degree to which you can harness the model is often quite comprehensive.  The major difference between custom instructions and deciding which is best for a particular AI platform is hard to track.  Usually it has to do with the amount of characters allowed to be saved in to the model's memory for your account.  In all cases though, we've been able to convey the Slop process effectively.
